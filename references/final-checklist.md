# 最终核对清单

核对实际原页，不凭记忆。

- [ ] 已读正文、表格图片、图注、报告要求、“不做”标记及用户更正。
- [ ] 任务数量正确，区分“观察四种”“画一种”“四组均画”。
- [ ] 没有新增原文未要求的测量项目、逐参数实测表或实验步骤。
- [ ] “不做”的实验没有进入实施步骤或结果记录。
- [ ] 原表方向、表号、字段名、行列顺序、单位与数值写法逐项一致。
- [ ] 未把某个参考图示例或估算方法写成教师指定项目。
- [ ] 必要理论计算有公式、代入和结果，不以空白代替要求计算的内容。
- [ ] 未提供的实测数据、现象、误差及实验结论留空。
- [ ] 参考数值与图按用户约定显著标记，不冒充实测。
- [ ] 空白图和参考图对应，所选序号、坐标单位、零位、档位符合要求。
- [ ] 所用方法读到了允许来源的正文；只有书目/目录时不伪造页码。
- [ ] 自行推导已标明；若用户不允许，则没有作为定稿方法。
- [ ] 来源在对应文字、图表旁，来源实际支持对应内容。
- [ ] 题干与条件正确，思考题位于要求位置，答案不扩写未问事项。
- [ ] 每一必做要求有去处，每一交付内容有要求依据。
- [ ] 图像链接有效，PDF公式与引用块内表格正确，图片清晰且无裁切。
- [ ] 修订后的Markdown、PDF及压缩包为同一版本。

有未完成项时说明具体限制，不把“公式正确”说成“指定教材已核实”，不把“参考图齐全”说成“实验已完成”。
